    How it learns

    Every heal, verifier revision and application defect becomes a signal. The learner reduces signals to root causes and stores one lesson per cause, scoped to the agent that could have prevented it — spec-author for how tests are written, story-analyzer for which behaviours exist, qe-auto-heal for known defects. The next cycle injects each lesson into that agent's turn.

    Lessons correct themselves: seen again → reinforced; applied and the problem stayed away → confirmed; applied but the problem came back → contradicted, losing confidence until it retires. A known-defect lesson resolves when the defect stops reproducing.

    Learning never touches an assertion. A test that caught a real defect stays red until someone fixes the application — try Mark fixed on a not-met row, then run another cycle.
