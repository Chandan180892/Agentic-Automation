    How it learns

    Every heal, verifier revision and application defect becomes a signal. The learner reduces signals to root causes and stores one lesson per cause, scoped to the agent that could have prevented it — spec-author for how tests are written, story-analyzer for which behaviours exist, qe-auto-heal for known defects. The next cycle injects each lesson into that agent's turn.

    Lessons correct themselves: seen again → reinforced; applied and the problem stayed away → confirmed; applied but the problem came back → contradicted, losing confidence until it retires. A known-defect lesson resolves when the defect stops reproducing.

    Learning never touches an assertion. A test that caught a real defect stays red until someone fixes the application — try Mark fixed on a not-met row, then run another cycle. Switch New lessons to “wait for my approval” and Reset memory to see learning pause until a person approves what it proposes.

    About & deploy

    Gantry is an agentic quality-engineering app. It reads Jira stories, plans the sprint, writes tests through a six-step pipeline, runs them, heals what drifted, reviews every acceptance criterion against the evidence, reports, and learns — so the next cycle makes fewer of the same mistakes.

    What this page is

    GitHub Pages serves static files only, so this page runs the agents in your browser on the same logic the server app uses when no API key is set: the same habits, heals, lesson bookkeeping and review rules. Nothing is sent anywhere. Memory lasts until you reload.

    What the full app adds

    Real Claude agents with typed, schema-checked output; Jira import; proposals to Xray, Bitbucket and Jira that an admin approves before anything is written; Postgres storage; background jobs that survive restarts; roles, audit log, rate limits and a daily token budget; health and readiness endpoints.

    Deploy the full app

    The repository includes a Render blueprint that creates the web service and a Postgres database together: on Render, choose New → Blueprint and point it at this repository. Or run the container image anywhere with a Postgres DATABASE_URL. Then set ANTHROPIC_API_KEY to take the agents off the simulator. The steps are in the README and docs/OPERATIONS.md.
