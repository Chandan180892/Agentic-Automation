The six agents

Each agent has one job, a typed input, and a typed output. They compose — the output of one is the input of the next — so a sprint walks from backlog to green without a human in the middle unless it asks for one.

Connect a machine

Run this on any box — your laptop, a CI worker, a bare-metal rack. It dials out to Gantry and starts claiming jobs.

# any machine, cloud or local
npx @gantry/runner connect \
  --token gnt_rnr_7f3c…a91 \
  --name my-laptop --slots 2
Requirements

Outbound HTTPS to gantry.app. No inbound ports, no VPN, no SSH key held by us. The token scopes to one workspace and can be revoked here.
