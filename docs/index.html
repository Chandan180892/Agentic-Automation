    About & deploy

    Autopilot is an agentic quality-engineering app. It reads Jira stories, plans the sprint, writes tests through a seven-step pipeline, runs them, heals what drifted, reviews every acceptance criterion against the evidence, reports, and learns — so the next cycle makes fewer of the same mistakes.

    What this page is

    GitHub Pages serves static files only, so this page runs the agents in your browser on the same logic the server app uses when no API key is set: the same habits, heals, lesson bookkeeping and review rules. Nothing is sent anywhere. Memory lasts until you reload.

    What the full app adds

    Real Claude agents with typed, schema-checked output; Jira import; proposals to Xray, Bitbucket and Jira that an admin approves before anything is written; Postgres storage; background jobs that survive restarts; roles, audit log, rate limits and a daily token budget; health and readiness endpoints.

    Deploy the full app

    The repository includes a Render blueprint that creates the web service and a Postgres database together: on Render, choose New → Blueprint and point it at this repository. Or run the container image anywhere with a Postgres DATABASE_URL. Then set ANTHROPIC_API_KEY to take the agents off the simulator. The steps are in the README and docs/OPERATIONS.md.
